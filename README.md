# Angel Technology Leadership Advisory

可直接部署至 GitHub Pages 的靜態網站。

## 六個檔案

- `index.html`：首頁、三方案、FAQ、流程與 CTA
- `terms.html`：服務條款、取消／改期／退款規則
- `privacy.html`：隱私權政策與個資告知
- `styles.css`：響應式共用樣式
- `script.js`：手機選單、方案選取、Email 詢問內容
- `README.md`：部署與正式營運檢查

## GitHub Pages 部署

1. 建立新的 GitHub repository，例如 `angel-career-site`。
2. 將六個檔案放在 repository 根目錄。
3. 到 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**。
6. 等待 GitHub Pages 顯示網站網址後，逐頁測試手機與桌面版。


## 已定稿：Executive Career Review 執行模式

- 顧問在主會談及收到完整資料後，提供第一版履歷重整稿。
- 客戶須在收到第一版後 10 日內，以單一文件或單封 Email 集中提出一次修改意見。
- 顧問依確認意見完成一次修改，再安排一次 45 分鐘複檢。
- 複檢以內容確認、重點說明及必要微調建議為主，不包含新增職涯方向、職缺、語言版本或全面重寫。
- 在客戶準時提供完整資料及回覆的前提下，方案原則於收到全額款項及完整必要資料的次一工作日起兩週內完成。
- 零散、多次、逾期或超出原範圍的修改需求，須另行確認時程與費用。

## 正式營運前必填資料

請全站搜尋並替換：

- `your-email@example.com`
- `［請填寫］`
- `［適用時填寫］`
- `［依法應揭露時填寫］`
- `［請依實際營運地及法律建議填寫］`

### A. 業者與聯絡資料

- 正式服務提供者或商號名稱
- 負責人姓名
- 統一編號（如適用）
- 正式服務 Email
- LINE 官方帳號
- 依法應揭露的營業或聯絡地址
- 客訴與個資權利申請聯絡方式
- 一般詢問的承諾回覆時間，例如 2 個工作天

### B. 交易與稅務

- 銀行轉帳或其他付款方式
- 何時提供匯款資料與如何核對款項
- 是否開立統一發票、收據或其他付款證明
- 報價是否含稅
- 退款手續費及跨行費用由誰負擔
- 商業登記、稅籍及發票義務，由台灣記帳士確認

### C. 服務執行

- 實際視訊工具，例如 Microsoft Teams 或 Zoom
- 預約方式與可服務時段
- 各方案真正交付的檔案格式，例如 Word、PDF 或視訊會議摘要
- 每一方案的修改輪次
- 交付天數起算點
- 客戶資料延遲時的順延方式
- 是否接受急件與急件報價規則
- 雙語、額外職缺、履歷超頁的報價方式

### D. 個資與工具

- 實際使用的 Email、雲端硬碟、視訊、表單、AI 與付款工具
- 履歷與會談工作檔案保存期限，例如服務完成後 12 個月
- 會計與交易紀錄保存期限
- 資料中心或跨境處理地區
- 是否錄音或錄影，以及同意方式
- 是否使用 Microsoft Copilot 或其他 AI 分析客戶資料
- 刪除、查詢、更正與停止利用的申請流程
- 資料事件的通知流程

### E. 首頁可信度

- 可公開且可驗證的 20+ 年經歷說明
- 2 至 4 項不涉及雇主或客戶機密的代表成果
- 可公開的專業證照或訓練
- 專業照片與替代文字（目前範本沒有放照片）
- 不使用未經授權的公司 Logo、客戶名稱或推薦內容

### F. 法律與上線檢查

- 由熟悉台灣消費者保護及個資法的律師檢查條款
- 由記帳士確認商業登記、稅籍及發票／收據義務
- 確認取消、改期、退款流程與實際人工流程一致
- 若增加 Google Analytics、Microsoft Clarity 或 Meta Pixel，更新隱私政策與 Cookie 告知
- 在手機、桌機及主流瀏覽器測試所有連結、Email CTA 與選單
- 不要把銀行完整帳號、身分證字號或私人電話寫入公開 GitHub repository

## 上線前建議

本網站已避免使用「一律不退款」或直接排除七日解除權等高風險絕對文字，但是否適用通訊交易解除權例外，仍取決於實際服務內容、事前告知、服務開始時間與台灣適用法律。公開收費前應完成專業審閱。
